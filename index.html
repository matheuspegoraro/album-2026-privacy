Figurinhas Scanner

Política de Privacidade

Sobre o app

Figurinhas Scanner é um aplicativo para gerenciar sua coleção de figurinhas do álbum de figurinhas 2026. O app funciona 100% offline, sem necessidade de conta ou cadastro.

Dados coletados

  • Coleção de figurinhas — armazenada localmente no dispositivo e sincronizada com nosso servidor para backup
  • Identificador anônimo do dispositivo — um UUID gerado aleatoriamente, sem vínculo com dados pessoais
  • Função de trocas (opcional) — se ativada pelo usuário: primeiro nome, número de WhatsApp e localização aproximada (~1km)

Como usamos os dados

  • A coleção é usada para sincronizar seus dados entre sessões e dispositivos
  • O primeiro nome e WhatsApp são exibidos apenas para outros usuários que também ativaram a função de trocas
  • A localização aproximada é usada exclusivamente para encontrar pessoas próximas para troca de figurinhas

Compartilhamento de dados

  • Seus dados de troca (nome e WhatsApp) são visíveis apenas para outros usuários que também ativaram a função
  • Não compartilhamos dados com terceiros
  • Sua localização exata nunca é armazenada ou compartilhada — apenas uma aproximação de ~1km

Seus direitos

  • Você pode desativar a função de trocas a qualquer momento
  • Você pode solicitar a exclusão completa dos seus dados diretamente no app
  • A coleção de figurinhas funciona 100% offline, sem necessidade de conta
  • Você pode limpar todos os seus dados a qualquer momento na tela "Mais"

Segurança

Utilizamos o Supabase com Row Level Security (RLS) para proteger seus dados. A comunicação entre o app e o servidor é criptografada via HTTPS.

Menores de idade

A função de trocas (que exibe WhatsApp) requer confirmação de que o usuário tem 18 anos ou mais. O álbum de figurinhas funciona sem qualquer coleta de dados pessoais.
